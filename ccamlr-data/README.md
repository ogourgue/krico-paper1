# CCAMLR Statistical Areas Shapefile

**Source:** CCAMLR GIS data repository (https://github.com/ccamlr/data)
**Tag:** v0.6.3 (23 March 2026)

Files included (all from `geographical_data/asd/`):

- `CCAMLR_ASD_EPSG4326.shp` — geometry
- `CCAMLR_ASD_EPSG4326.shx` — shape index
- `CCAMLR_ASD_EPSG4326.dbf` — attributes
- `CCAMLR_ASD_EPSG4326.prj` — coordinate reference system
- `CCAMLR_ASD_EPSG4326.cpg` — character encoding (if present)

These files define the CCAMLR Statistical Areas, Subareas and Divisions
in WGS84 (EPSG:4326). Used by F1, F4, and F5 figure scripts for subarea
outlines and per-subarea spatial analyses.

Please cite CCAMLR as the data source if you use this shapefile in your
own work.
